Architecture

Primitives → system → components

Tokens are layered in three tiers. Primitives are raw values — six full color ramps, a type scale, a spacing scale — named by position, not intent (--color-gray-500). System aliases give those primitives intent (--color-bg-default, --color-fg-muted) and are the only layer redefined between light and dark mode. Components — buttons, chips, cards — consume system aliases exclusively, never primitives directly, so re-theming the whole site is a one-file edit in tokens.css.
